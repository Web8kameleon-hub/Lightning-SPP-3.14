## License Activation

### How It Works

1. **Purchase** - Select your plan and complete payment via Stripe Checkout
2. **Receive License Key** - Emailed automatically within minutes of payment
3. **Activate** - Paste the key into your [workspace dashboard](https://scanprocessprint.com/dashboard) — no administrator access code required
4. **Start Using** - All features unlocked immediately

### License Key Format

```
LSPP-XXXX-XXXX-XXXX-XXXX
```

### Activation Process

```csharp
// In your application
LightningAPI.ActivateLicense("LSPP-XXXX-XXXX-XXXX-XXXX");
```

Or via configuration:
```json
{
  "LightningLicense": {
    "Key": "LSPP-XXXX-XXXX-XXXX-XXXX",
    "Type": "Unlimited"
  }
}
```

## Frequently Asked Questions

### Can I switch plans?

**Yes!** You can upgrade or downgrade anytime:
- **Upgrade:** Immediate, pro-rated credit applied
- **Downgrade:** Effective at next renewal

### What happens if I exceed Pay-As-You-Go limit?

Processing continues, you're charged for actual usage. No service interruption.

### Can I cancel Unlimited plan?

Yes, cancel anytime. **No refunds** for unused time, but access continues until expiration.

### Do you offer free trials?

**Developer Edition is always free!** Test in production with Pay-As-You-Go (pay only for what you use).

### Is there a setup fee?

**No setup fees** for any plan. Pay only the subscription/usage cost.

### What's your refund policy?

- **Pay-As-You-Go:** Refunds available within 30 days for unused credits
- **Unlimited:** No refunds, but cancel anytime
- **Enterprise:** Custom terms in contract

### Do licenses expire?

- **Pay-As-You-Go:** Active as long as you have credits
- **Unlimited:** Expires after 365 days (renewable)
- **Enterprise:** Per contract terms

### Can I transfer my license?

**Unlimited & Enterprise:** Yes, contact us for transfer  
**Pay-As-You-Go:** Non-transferable (account-based)
