# Lightning SPP Stepstones (Contributor Roadmap)

Ky dokument i ndihmon kontribuesit të hyjnë shpejt në projekt.

## Stepstone 1 - First contribution (30-60 min)
- Fix typo/clarity në `README.md` ose `Wiki/*`
- Hap PR me label `documentation`

## Stepstone 2 - Good first code issue (1-3 orë)
- Zgjidh një issue me `good-first-issue`
- Shto test minimal në `Tests/*`

## Stepstone 3 - API/CLI improvement (gjysmë dite)
- Përmirëso endpoint te `Web/LicenseApiServer.cs` ose command te `Program.cs`
- Përditëso `openapi.json`

## Stepstone 4 - Performance / Real services
- Optimizo `RealImageProcessor`, `RealAIProcessor`, `RealPrintService`
- Shto benchmark ose test krahasues

## Stepstone 5 - Maintainer path
- Triage issues
- Review PRs
- Ndihmo me release checklist
