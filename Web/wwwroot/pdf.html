Limits and availability

  • PDF only, up to 8 MiB and 32 pages.
  • Page 1 preview; the download contains all processed pages.
  • Pages are rasterized; selectable text, vectors and PDF metadata are not preserved.
  • Encrypted PDFs are rejected. Processing failures return no partial PDF.
  • Output may be larger than the input. This is not a lossless PDF optimizer.
  • Requests are rate-limited to 10 per visitor per 5 minutes.
  • Native PDF processing requires Poppler in the application environment.
  • This workflow is available on this application instance. Availability alone does not establish suitability for a customer deployment.
  • Only the Lightning grayscale profile is offered here. Other profiles need further PDF dimension-limit verification.

This workflow is available on this application instance; it is not a claim of commercial readiness.
