How can I integrate image processing into a .NET application?

Call LightningAPI from your .NET 10 application for scan, process, output and batch operations, or run the CLI from scripts. The REST API documentation covers workspace licensing, health, billing and the image processing demo.

Start with the SDK installation and code examples, compare developer and production plans, and review the image processing benchmarks before testing your own workload.

Good to know

Can I scan or print from this website?

You can upload a document or image to the browser demo to run the real document, Scan and Process stages. It accepts PDF, JPEG, PNG, BMP, TIFF and GIF files up to 8 MB. PDF files are validated and rendered through the Lightning document core before processing. Physical scanning and printing require a connected application and platform-specific adapters.

What is a license?

A license gives your workspace access to a plan. The license page shows whether that access is active. You do not need to enter any technical information to check it.

Who can help me get started?

Contact the person or team who set up Lightning SPP for you. They can activate your workspace license and help you find the right application.
