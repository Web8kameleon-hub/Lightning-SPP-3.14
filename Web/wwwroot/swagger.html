Lightning SPP REST API documentation

Explore 25 HTTP operations for runtime health, workspace licensing, customer registration and login, customer licenses, Stripe billing and real image/PDF processing. The interactive reference below shows request parameters, response schemas and authorization requirements.

For customer requests, first fetch /api/account/csrf and keep its cookie. Send JSON from this site's origin with the returned token in X-CSRF-Token. Obtain a fresh token after login. Administrator operations require a separate bearer token; Stripe webhooks require Stripe's signature.

Download the OpenAPI specification. For the scan, process and output SDK, see the .NET SDK installation and examples.

The SDK's Scan, Process and Output interfaces and Linux CUPS/SANE adapters are separate from these HTTP operations. Longo storage uses a private API and is not exposed through this reference.
