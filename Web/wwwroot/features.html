What Lightning SPP does

A modular Scan → Process → Print
pipeline for .NET 10.

Lightning SPP runs real image processing, AI-assisted enhancement, and lossless compression — not simulated timers. Pick a profile, run the pipeline, get a real artifact on disk.

See pricingHow it works

The three stages

1

Scan

Lightning, TideWave, Resonance and NanoDecibel modes trade off speed, balance, and precision depending on the input and device profile (desktop, mobile, IoT, cloud).

2

Process

Real transforms via SkiaSharp/ImageSharp (edge detection, sharpening, contrast) plus an Microsoft.ML context for AI-assisted enhancement through the CLX, CLI.I, XCL, Hybrid and Clisonic Global AI engines.

3

Print

Stigma produces a lossless Brotli-compressed artifact written to disk. Draft, Normal and High quality levels are also available. Physical printer integration requires a platform-specific adapter.

Adaptive Stigma profiles

A single environment variable, WWWMMM_STIGMA_LEVEL, controls the entire pipeline's behavior end-to-end:

ValueProfileBehavior
1qualityNanoDecibel, Hybrid + AI, lossless Stigma output
2balancedTideWave, Auto + AI, high output quality
3lightningLightning, CLX fast path, skips costly phases

Invalid values are rejected at startup rather than silently coerced, so misconfiguration fails loudly instead of degrading quality unnoticed.

Built on real components, not simulations

Image processing

SkiaSharp and SixLabors.ImageSharp perform real transforms — edge detection, Gaussian sharpening, contrast — instead of artificial delays.

AI context

Microsoft.ML and ONNX Runtime provide the AI/ML context used by the Hybrid and Clisonic Global AI engines.

Compression

Brotli produces real, lossless compressed artifacts — the same compression format used in production web and storage systems.

Output

Every run writes a real file to disk. No mocked results, no non-deterministic demo output.

Multiple ways to integrate

REST API

HTTP endpoints for health, license management, and Stripe billing. See the API documentation.

.NET SDK

Call LightningAPI directly from your .NET 10 application for scan, process, print, batch and hybrid operations.

CLI

wwwmmm scan|process|print|pipeline|batch|serve|speed — automate from scripts or CI.
