# Stigma Glossary

## Core Terms
- Stigma: resonance-aware processing ecosystem for scan-process-print.
- Resonance: coherence behavior of transformed signal under mode-specific processing.
- NdB (NanoDecibel): scaled decibel signature used for micro-level signal characterization.
- Tide: wave-like transform stage emphasizing field continuity.
- Imprint: stabilized output field representation after resonance and enhancement stages.
- Fluid memory: conceptual persistence of transformation identity across pipeline phases.
- Stabilization: step that reduces transformation volatility and preserves deterministic output intent.

## Pipeline Terms
- Scan: source acquisition from binary or image input.
- Enhancement: transform step that improves perceptual or structural signal quality.
- Print: persistence of final artifact in compressed output format.

## Engine Terms
- CLX: fastest compression-oriented path.
- CLX.i: balanced speed/ratio path.
- XCL: maximum compression path with memory pooling.

## Quality Terms
- Lightning mode: minimal-latency transform profile.
- TideWave mode: coherence-focused transform profile.
- Resonance mode: edge/tension-focused transform profile.
- NanoDecibel mode: highest-fidelity transform profile.
