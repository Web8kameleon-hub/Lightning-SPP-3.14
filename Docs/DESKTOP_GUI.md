# Lightning SPP Desktop GUI

WinForms drag-and-drop scaffold is available at:

- `Desktop/LightningSPP.Desktop`

## Build and run

```bash
dotnet run --project Desktop/LightningSPP.Desktop/LightningSPP.Desktop.csproj
```

## Features

- Drag-and-drop file loading
- Pipeline run against selected file
- Basic status updates
